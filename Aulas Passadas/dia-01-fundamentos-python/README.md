# Dia 1: fundamentos de Python

Primeiro dia. Transição do Portugol para o Python, ainda sem Orientação a Objetos.
O foco é entrada de dados, condições, laços e funções.

## Material

- `slides.pptx`: slides usados na aula.

## Códigos

- `soma_media.py`: soma e média de valores.
- `soma_sentinela.py`: soma que termina com um valor sentinela.
- `tabuada.py`: tabuada com laço.
- `validacao_nota.py`: leitura e validação de nota.
- `menu_calculadora.py`: menu com opções e `if/elif/else`.
- `sistema_pedidos.py`: pequeno sistema de pedidos.
- `varias_turmas.py`: laços encaixados para várias turmas.
- `exercicios.py`: exercícios do dia.

## Respostas

A pasta `respostas/` guarda as soluções do aluno.

## Como rodar

```
python3 nome_do_arquivo.py
```
